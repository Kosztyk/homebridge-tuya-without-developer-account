Tuya QR Cloud Authentication

This plugin connects Tuya / Smart Life devices to Homebridge using the same QR authorization style used by the official Home Assistant Tuya integration. It does not need a Tuya IoT developer account, Access ID, Access Secret, cloud project, username, or password.

In the Tuya Smart or Smart Life app, find the User Code under account/security settings, then paste it here.
Scan this QR code with the Tuya Smart or Smart Life mobile app.
Enter your User Code, click Generate QR Code, then scan with the Tuya Smart or Smart Life app.
Adaptive Lighting

Enable HomeKit Adaptive Lighting only for eligible Tuya lights that expose both brightness and real white color-temperature controls. RGB-only lights, dimmer plugs, switches, and outlets are skipped automatically.

HomeKit automatic mode may send color-temperature updates roughly once per minute while Adaptive Lighting is active.
HomeKit Names

Preserve names assigned in Apple Home so multi-gang switches and outlets do not return to generated names such as Brilliant 1 and Brilliant 2 after every Homebridge restart. You can also set explicit channel names below.

When enabled, the plugin pushes the names shown in Homebridge Accessories into HomeKit Name and ConfiguredName for all services on every restart. Explicit channel names still take priority.

Pet Feeder

Apple Home does not provide a native Pet Feeder tile. This plugin still supports real Tuya pet feeders when Tuya reports the correct cwwsq category, but the custom Pet Feeder override UI has been removed to avoid forcing blinds, switches, or other devices into the wrong handler.

Blind / Window Covering Overrides

Fix Tuya blind calibration mismatches. HomeKit expects 0 = closed and 100 = open. Some Tuya motors report the opposite, or have open/close movement commands reversed.

Blind-looking devices are listed first when the cached Tuya device list contains enough metadata.
Use when the Home app shows open when the blind is actually closed, or closed when it is actually open.
